# Вклад в проект

**Спасибо за интерес к проекту.** Ниже приведены рекомендации по внесению изменений.

## Структура проекта

```
scientific-publications/
├── papers/              # Научные статьи и публикации
├── projects/            # Программные проекты
│   ├── project-name/
│   │   ├── src/
│   │   ├── tests/
│   │   ├── configs/
│   │   ├── pyproject.toml
│   │   └── README.md
├── .github/workflows/   # CI/CD пайплайны
└── publications.bib     # Библиография
```

## Требования к новым проектам

1. **Структура проекта**
   - Используйте `pyproject.toml` для управления зависимостями
   - Размещайте код в `src/`
   - Добавляйте тесты в `tests/`
   - Включайте `README.md` с описанием

2. **Качество кода**
   - Линтинг с `ruff`
   - Форматирование с `black` (line-length: 100)
   - Типизация с `mypy`

3. **Документация**
   - docstrings для всех функций и классов
   - Примеры использования в README

## Процесс разработки

1. Создайте ветку от `dev`:

   ```bash
   git checkout dev
   git checkout -b feature/your-feature
   ```

2. Установите pre-commit хуки:

   ```bash
   poetry install
   pre-commit install
   ```

3. Внесите изменения и протестируйте

4. Отправьте пул-реквест в `dev`

## Проверки перед коммитом

```bash
# Проверка качества кода
ruff check .
black --check .
mypy .

# Запуск тестов
pytest projects/

# Автоматическая проверка (pre-commit)
pre-commit run --all-files
```

## Публикации

**При добавлении новой публикации:**

1. Создайте папку в `papers/YYYY/`
2. Обновите `README.md` с DOI и описанием
3. Добавьте запись в `publications.bib`

## Стиль кода

- **Имена переменных**: `snake_case`
- **Константы**: `UPPER_CASE`
- **Классы**: `PascalCase`
- **Максимальная длина строки**: 100 символов

## Лицензия

Внося изменения, вы соглашаетесь, что ваш вклад распространяется под лицензией MIT.
