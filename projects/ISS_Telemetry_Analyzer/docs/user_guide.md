# 📖 Руководство пользователя ISS Telemetry Analyzer

## 🎯 Введение

ISS Telemetry Analyzer - это комплексный инструмент для сбора, анализа и визуализации телеметрических данных Международной космической станции. Данное руководство поможет вам максимально эффективно использовать все возможности системы.

## 🚀 Начало работы

### Системные требования

- **Операционная система**: Windows, macOS или Linux
- **Python**: версия 3.8 или выше
- **Интернет-соединение**: для получения данных от API
- **Свободное место на диске**: не менее 100 МБ

### Установка

1. Убедитесь, что у вас установлен Python 3.8+
2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/QuadDarv1ne/scientific-publications/projects/ISS_Telemetry_Analyzer.git
   ```
3. Перейдите в директорию проекта:
   ```bash
   cd scientific-publications/projects/ISS_Telemetry_Analyzer
   ```
4. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

### Режимы работы

#### 1. Орбитальная телеметрия
Анализ текущего положения и параметров орбиты МКС:
- Получение текущих координат
- Расчет орбитальной скорости
- Визуализация трека на карте
- 3D визуализация орбиты

#### 2. Условия окружающей среды
Анализ температурных условий и радиации:
- Симуляция температурного профиля
- Моделирование радиационного фона
- Анализ высоты орбиты
- Генерация телеметрического отчета

#### 3. Комплексный анализ
Полный анализ всех параметров:
- Комбинирование орбитального и экологического анализа
- Расширенная визуализация
- Комплексные отчеты

#### 4. Запуск тестов
Проверка корректности работы системы:
- Запуск unit-тестов
- Проверка функциональности модулей
- Валидация результатов

#### 5. Методология исследования
Просмотр научной методологии:
- Описание подходов к анализу
- Обоснование методов
- Источники данных

#### 6. Расширенный орбитальный анализ
Глубокий анализ орбитальных параметров:
- Анализ тренда изменения высоты
- Частотный анализ пролетов
- Расширенная 3D визуализация

#### 7. Расширенный анализ условий среды
Глубокий анализ экологических условий:
- Анализ пиков радиации
- Расширенное моделирование температур
- Долгосрочные прогнозы

## 📊 Работа с данными

### Структура данных

Все данные сохраняются в следующей структуре:

```
data/
├── tle_data/              # TLE данные МКС
└── collected_telemetry/   # Собранные телеметрические данные

results/
├── plots/                 # Графики и визуализации
├── reports/               # Текстовые отчеты
└── analysis/              # Результаты анализа
```

### Форматы файлов

- **JSON**: структурированные данные
- **PNG**: графики и визуализации
- **CSV**: табличные данные (экспорт)

### Пример структуры данных

#### TLE данные
```json
{
  "name": "ISS (ZARYA)",
  "line1": "1 25544U 98067A...",
  "line2": "2 25544 51.6400...",
  "timestamp": "2025-11-09T21:34:44.123456"
}
```

#### Телеметрический отчет
```json
{
  "report_date": "2025-11-09T21:34:44.123456",
  "orbital_parameters": {
    "altitude_km": 408.0,
    "inclination_deg": 51.64,
    "period_min": 92.9,
    "velocity_kms": 7.66
  },
  "temperature": {
    "internal_min": 18,
    "internal_max": 27,
    "external_sun": 121,
    "external_shadow": -157
  }
}
```

## 📈 Визуализация

### Типы графиков

#### 2D трек МКС
Отображает путь МКС на карте Земли за определенный период.

#### 3D орбита МКС
Показывает трехмерную траекторию орбиты МКС относительно Земли.

#### Температурный профиль
График изменения температуры внутри и снаружи модулей МКС.

#### Радиационный фон
График уровней космической радиации с выделением пиков.

#### Высота орбиты
График изменения высоты орбиты с учетом атмосферного торможения.

#### Накопленная доза радиации
График накопленной радиационной дозы за период времени.

### Настройка визуализации

Все графики можно настраивать:
- **Продолжительность**: от нескольких часов до нескольких дней
- **Сохранение**: автоматическое сохранение в формате PNG
- **Отображение**: возможность показа или скрытия графиков

## 🔭 Прогнозирование

### Прогноз видимости

Функция прогноза видимости позволяет определить, когда МКС будет видна с конкретной точки на Земле:
```python
from src.iss_orbital_analysis import predict_passes

# Прогноз для Москвы
predict_passes(latitude=55.7558, longitude=37.6173, n_passes=5)
```

### Частотный анализ

Анализ частоты пролетов МКС над заданной точкой:
```python
from src.iss_orbital_analysis import analyze_pass_frequency

# Анализ частоты пролетов над Москвой за 7 дней
frequency_data = analyze_pass_frequency(55.7558, 37.6173, days=7)
```

Для добавления прогноза видимости для новых городов:
```python

    "Санкт-Петербург": (59.9343, 30.3351),
    "Новосибирск": (55.0084, 82.9357),
}

for city, (lat, lon) in cities.items():
    print(f"\n{city}:")
    predict_passes(lat, lon, n_passes=3)
```

## 🐛 Решение проблем

### Частые проблемы

1. **Нет подключения к интернету**
   - Проверьте интернет-соединение
   - Убедитесь, что API доступны

2. **Ошибки при установке зависимостей**
   - Обновите pip: `pip install --upgrade pip`
   - Попробуйте установить зависимости по отдельности

3. **Ошибки при запуске тестов**
   - Убедитесь, что все зависимости установлены
   - Проверьте версию Python

### Логирование

Система использует расширенное логирование для диагностики проблем:
- **INFO**: общая информация о работе
- **WARNING**: предупреждения
- **ERROR**: ошибки
- **DEBUG**: отладочная информация
