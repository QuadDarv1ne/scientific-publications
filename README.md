  > Несмотря на практическую эффективность адаптивных оптимизаторов (*например, `Adam`*), их теоретический анализ ограничен субгауссовскими предположениями, что создает пробел в робастности реальных систем.

  > **Представляю вашему вниманию AdaHeavy** — принципиальную методику адаптивной оптимизации при слабых предположениях о моментах.

  > Данный подход интегрирует моментно-адаптивный клиппинг градиентов в `Adam` и `AdaGrad`, динамически настраивая пороги клиппинга на основе (1+δ) -го момента (δ∈(0,1] ) исторических градиентов.
  
  > Доказано, что `AdaHeavy` обеспечивает сходимость O(Tlog(1/δ)) с вероятностью 1−δ для невыпуклых липшицевых функций — первый результат для адаптивных методов при тяжелых хвостах.

  > *Анализ основан на новом подходе стохастического дрейфа функции Ляпунова, учитывающем зависимость между порогами клиппинга и историей градиентов.*
